# Fluentdat

A chat app I am building, Discord style, on GitHub Pages: servers and channels, stickers, themes you can switch, a camera and mic preview for calls, and slash commands.

Live: https://trixwotel.github.io/Fluentdat/

## Now

The app runs in your browser and saves messages there (localStorage), so you can try it, and two windows side by side talk to each other.

## Next

Team sync over GitHub: messages save to a private repo (one message, one commit), signed in with your own GitHub, so a small group shares a server. Then real voice and video between teammates (WebRTC).
